# SOC Internship Project – Week 1
## Wireshark Network Traffic Analysis

### Project Overview
This project documents six Wireshark-based network analysis exercises completed as part of my SOC internship training.

### Labs Completed
1. Lab 3 – Identify the Attacker's IP
2. Lab 4 – Follow TCP Stream 1
3. Lab 5 – Follow TCP Stream, Part 2
4. Lab 6 – HTTP Plain Text Credentials
5. Lab 7 – Catch the Brute Force Attacker
6. Lab 8 – Catch the Call Scammer

### Tools and Techniques
- Wireshark
- Network packet analysis
- TCP stream inspection
- HTTP and FTP traffic analysis
- SIP and RTP analysis
- IP address identification
- Brute-force attack detection
- Credential exposure investigation

### Key Learning Outcomes
- Identifying suspicious network activity.
- Analyzing network protocols and packet captures.
- Detecting credential exposure and authentication attacks.
- Investigating VoIP communication and social engineering risks.
- Documenting security findings and recommending mitigation measures.

### Disclaimer
This repository contains educational lab exercises conducted in a simulated environment. Sensitive credentials and personal information have been redacted.
